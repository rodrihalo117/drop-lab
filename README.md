# Drop Lab

Patio de recreo de física 3D: suelta esferas, cajas y cilindros, apílalos, arrástralos y derrúmbalos.

**Jugar ahora:** [abrir Drop Lab](https://raw.githack.com/rodrihalo117/drop-lab/main/index.html)

Código: este mismo repositorio. Un solo `index.html` con Three.js + Rapier.

## Cómo jugar

- **Esfera / Caja / Cilindro** — suelta una forma (`1` `2` `3`)
- **Toca el suelo** — suelta la forma activa en ese punto
- **Arrastra** un cuerpo para moverlo y lanzarlo al soltar
- **Órbita** — arrastra el fondo para girar la cámara; rueda para zoom
- **Lluvia** (`R`) — 12 formas mixtas desde el cielo
- **Limpiar** (`C`) — vacía el mundo
- **Pausa** (`P`)
- **Espacio** — suelta la forma activa desde arriba
- **Gravedad** y **Rebote** (restitución) — deslizadores en la barra

Máximo 80 cuerpos. La simulación arranca con una torre ya apilada.
