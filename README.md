# Drop Lab

Patio de recreo de física 3D: suelta esferas, cajas y cilindros, apílalos, arrástralos y derrúmbalos.

## Cómo jugar

Abre `index.html` en el navegador (o usa GitHub Pages).

- **Esfera / Caja / Cilindro** — suelta una forma (teclas `1` `2` `3`)
- **Toca el suelo** — suelta la forma activa en ese punto
- **Arrastra** un cuerpo para moverlo y lanzarlo
- **Órbita** — arrastra el fondo para girar la cámara; rueda para zoom
- **Lluvia** (`R`) — 12 formas mixtas
- **Limpiar** (`C`) — vacía el mundo
- **Pausa** (`P`)
- **Espacio** — suelta la forma activa
- Deslizadores de **gravedad** y **rebote** (restitución)

Máximo 80 cuerpos. Simulación Rapier a 60 Hz.
